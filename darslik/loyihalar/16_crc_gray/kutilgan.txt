  0x01 -> 1
  0xFF -> 0
  0xB7 -> 0
Bitlarni teskari aylantirish:
  0x01 -> 0x80
  0x0F -> 0xF0
  0xA5 -> 0xA5
  0x1D -> 0xB8
Gray kodi (n -> gray -> orqaga):
  0 -> 0 -> 0
  1 -> 1 -> 1
  2 -> 3 -> 2
  3 -> 2 -> 3
  4 -> 6 -> 4
  5 -> 7 -> 5
  6 -> 5 -> 6
  7 -> 4 -> 7

  "" -> 0x00
  "A" -> 0xC0
  "123456789" -> 0xF4
  "Salom, dunyo!" -> 0x8D
  "Samom, dunyo!" (3-bayt buzilgan) -> 0x92
